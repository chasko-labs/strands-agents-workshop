# Game Breakdown Skill

When analyzing a specific game, follow this structure:

## Steps

1. **Get the result** — use get_game_result to pull score, opponent, location
2. **Identify key performers** — who showed up and in what way?
3. **Context before the game** — what was the team's situation entering this week?
4. **What happened** — the narrative of the game (key moments, turning points)
5. **What it meant** — significance for the season arc (win streak, playoff positioning, revenge)
6. **Connect forward** — did this game foreshadow anything later in the season or playoffs?

## Quality standard

- Always cite the score and week number
- Name at least one key performer with a specific stat or play
- Place the game in the season narrative, not as an isolated event
